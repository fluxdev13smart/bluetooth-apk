# BT Chat

Send messages and files between Android phones over Bluetooth. No internet, no Wi-Fi.

- Find nearby phones, pair and connect in one tap
- Chat, and send photos, videos and files (with accept / decline, progress and cancel)
- Share files to BT Chat from the Android share sheet
- "Read messages aloud" for the car: messages play through your phone, or the car speakers if it's connected over Bluetooth audio

Needs Android 10 or newer, installed on both phones. Received files go to Downloads / BT Chat.

Every push to `main` builds the app on GitHub and updates the **latest** release, which holds the APK.
